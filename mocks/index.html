Data Model Concept

Trip (paramount entity)
├── name, dates, type, description
└── items[] (loose collection organized by date)
    ├── Flight { from, to, date, time, carrier, flight#, confirmation }
    ├── Hotel { name, location, checkIn, checkOut, confirmation }
    ├── Train { from, to, date, time, carrier }
    ├── Drive { from, to, date, rentalCompany? }
    ├── Event { name, date, time, location }
    └── Document { name, file, type, amount? }
